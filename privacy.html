Privacy policy

IceNode Drive Sync · effective 2026-11-25

What data it handles

The tool handles only scientific instrument data (sensor logs, telemetry and camera images of the under-ice environment) that the research team itself produces. It collects no personal information about anyone.

How it uses Google account access

The team's Google account authorizes the tool once. The tool uses that access only to upload the team's data files to the team's own Drive folder and to list that folder so it doesn't upload a file twice. The access token is stored only on the team's ground station computer.

Sharing

The tool does not sell, share or transfer any data to anyone. Files go only to the team's own Google Drive. Google's handling of data in Drive is covered by Google's own privacy policy.

Retention and deletion

The tool keeps no copy of Google account data beyond the access token on the ground station. The team can revoke the tool's access at any time from its Google Account's security settings, which stops all access immediately.
